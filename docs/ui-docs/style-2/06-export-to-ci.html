Run dvwa scans automatically

We don't schedule scans ourselves — we give you a workflow for the app's own repository.

Choose when it runs

.github/workflows/dast-dvwa.yml

Checked
name: dast-dvwa
on:
  schedule: [{ cron: "0 6 * * 1" }]
  workflow_dispatch:
permissions: { contents: read, security-events: write }
jobs:
  scan:
    runs-on: ubuntu-latest
    timeout-minutes: 45
    steps:
      - uses: actions/checkout@v4
      - run: echo "ZAP_API_KEY=$(openssl rand -hex 24)" >> "$GITHUB_ENV"
      - run: docker compose up -d zap
      - env: { DVWA_USER: ${{ secrets.DVWA_USER }}, DVWA_PASS: ${{ secrets.DVWA_PASS }} }
        run: |
          python -m dast author dvwa --no-llm
          python -m dast scan   dvwa
      - run: python -m dast report dvwa --upload --ref "$DEPLOYED_REF" --commit "$DEPLOYED_SHA"
Add DVWA_USER and DVWA_PASS as repository secrets before the first run.

What the result means

0Scan was healthy and the gate passed
1New finding at or above the gate, or the scan wasn't healthy
2Refused or misconfigured
3AI was required but unavailable
