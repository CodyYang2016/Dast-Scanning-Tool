Problem 1 of 19 · serious

Someone could read or change your database through the "User ID" box

This is called SQL injection. On /vulnerabilities/sqli, whatever is typed into id goes straight into a database query.

How we know

We typed 1' OR '1'='1' -- and the page replied with a database error:

You have an error in your SQL syntax; check the manual that
corresponds to your MySQL server version

How to fix it

Use parameterized queries (prepared statements) for every value that reaches the database, and check that id is a whole number before using it.
