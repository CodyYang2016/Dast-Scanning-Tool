How we talk about settings

Every setting falls into one of four groups. You'll see these notes throughout.

!We need this from youThere's no safe guess, so we can't scan without it.
~You can leave this as it isIt has a sensible default. Change it only if you have a reason.
?Someone else decides thisIt changes what a scan is allowed to do, so an approver signs it off.
=This is always onA safety rule, or something we work out for you.
